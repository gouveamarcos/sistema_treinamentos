Manual para técnicos e participantes da Academia Técnica Sem Parar.

1. Objetivo da plataforma

A Academia Técnica Sem Parar é a plataforma usada para acessar cursos, treinamentos, avaliações e certificados.

Nela você pode:

  • criar seu primeiro acesso;
  • entrar com usuário e senha;
  • visualizar cursos liberados para você;
  • assistir aulas e ler conteúdos;
  • responder testes e provas;
  • acompanhar seu progresso;
  • emitir certificado quando concluir um curso;
  • validar um certificado pelo código público.

2. Acesso ao sistema

Acesse o endereço informado pela empresa ou pelo responsável operacional.

Na tela inicial, você encontrará as opções:

  • Entrar: para quem já tem senha cadastrada;
  • Primeiro acesso: para criar a senha pela primeira vez;
  • Esqueci minha senha: para redefinir o acesso;
  • Validar certificado: para consulta pública de certificados.

3. Primeiro acesso

Use esta opção quando ainda não tiver senha.

  1. Clique em Primeiro acesso.
  2. Informe o e-mail cadastrado.
  3. Informe sua matrícula.
  4. Crie uma senha segura.
  5. Confirme a senha.
  6. Envie o formulário.

Depois disso, o sistema cria seu usuário e libera o acesso à área de cursos.

Se o primeiro acesso não funcionar

Verifique:

  • se o e-mail foi digitado igual ao cadastro;
  • se a matrícula está correta;
  • se você já não criou acesso anteriormente;
  • se seu cadastro está ativo.

Se ainda assim não conseguir entrar, procure o responsável operacional.

4. Login

  1. Acesse a tela de login.
  2. Informe seu usuário.
  3. Informe sua senha.
  4. Clique em Entrar.

Normalmente, seu usuário será o e-mail cadastrado.

5. Recuperar senha

Use esta opção se esqueceu sua senha.

  1. Clique em Esqueci minha senha.
  2. Informe o e-mail cadastrado.
  3. Verifique sua caixa de entrada.
  4. Abra o link recebido.
  5. Crie uma nova senha.

O link de recuperação é temporário. Se expirar, solicite outro.

6. Página inicial

Depois de entrar, você verá os cursos disponíveis para você.

Cada curso pode mostrar:

  • nome do curso;
  • produto relacionado;
  • situação do progresso;
  • acesso às etapas;
  • certificado, quando disponível.

7. Como fazer um curso

  1. Entre no sistema.
  2. Clique no curso liberado.
  3. Acesse a primeira etapa disponível.
  4. Leia o conteúdo ou assista ao vídeo.
  5. Marque a etapa como concluída quando terminar.
  6. Avance para a próxima etapa.
  7. Responda testes ou provas quando aparecerem.

As etapas são liberadas em ordem. Se uma etapa estiver bloqueada, conclua a etapa anterior primeiro.

8. Videoaulas

Quando a etapa for do tipo vídeo, o conteúdo aparecerá dentro da própria página.

Se o vídeo estiver hospedado no YouTube, ele será exibido por link incorporado. Caso o vídeo não abra:

  • verifique sua conexão;
  • tente atualizar a página;
  • confirme se a rede da empresa permite acesso ao YouTube;
  • avise o responsável operacional se o vídeo parecer indisponível.

9. Testes e provas

Algumas etapas podem ter perguntas de múltipla escolha.

Para responder:

  1. Leia o enunciado.
  2. Escolha uma alternativa.
  3. Responda todas as questões.
  4. Clique em Enviar respostas.

Em provas finais, pode existir nota mínima para aprovação.

Se você for reprovado, o sistema pode reiniciar o progresso do curso para uma nova tentativa, conforme a regra configurada.

10. Conclusão e certificado

Ao concluir todas as etapas obrigatórias e ser aprovado quando houver prova, o sistema registra a conclusão do treinamento.

Quando o certificado estiver disponível, você poderá visualizar:

  • nome do técnico;
  • empresa;
  • curso;
  • produto;
  • data de conclusão;
  • validade, quando existir;
  • código do certificado.

11. Imprimir ou salvar certificado

Na tela do certificado:

  1. Abra o certificado.
  2. Use a opção de impressão do navegador.
  3. Se desejar PDF, escolha Salvar como PDF na janela de impressão.

12. Validação pública de certificado

Qualquer pessoa com o código do certificado pode validar a autenticidade em:

/certificados/validar/

O código tem formato parecido com:

CERT-XXXXXXXX

Ao consultar, o sistema informa se o certificado existe e mostra os dados principais da conclusão.

13. Reciclagem e vencimento

Alguns certificados têm validade.

Quando uma certificação vence, o curso pode voltar a ficar pendente para nova realização. O sistema também pode enviar lembretes por e-mail quando houver treinamentos vencidos ou próximos do vencimento.

14. Boas práticas de segurança

  • Não compartilhe sua senha.
  • Use uma senha forte.
  • Não envie seu certificado para terceiros sem necessidade.
  • Sempre confira se está no endereço correto da plataforma.
  • Saia do sistema ao usar computador compartilhado.

15. Problemas comuns

Não consigo entrar

Use Esqueci minha senha. Se não receber o e-mail, procure o responsável.

Meu curso não aparece

O curso precisa estar liberado para você. Procure o responsável operacional.

A etapa está bloqueada

Conclua as etapas anteriores na ordem.

O vídeo não abre

Verifique internet, bloqueios de rede e disponibilidade do YouTube.

Meu certificado não aparece

Confirme se todas as etapas foram concluídas e se a prova final foi aprovada.

16. Quem procurar

Procure o responsável operacional da sua empresa quando precisar de:

  • cadastro ou correção de dados;
  • liberação de cursos;
  • reativação de treinamento;
  • orientação sobre certificado;
  • suporte para primeiro acesso.
