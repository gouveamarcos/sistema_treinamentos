# Fragmentos de conferência preservados

`parse.ps1` e `snippet.ps1` foram usados durante a verificação dos exemplos dos manuais. Foram mantidos para preservar os arquivos existentes na reorganização.

Não são scripts de instalação e não devem ser executados no servidor. O verificador em `docs/ferramentas/verificar.py` pode sobrescrever `snippet.ps1` ao conferir a sintaxe de um novo exemplo. `parse.ps1` é um fragmento histórico que não é usado pelo verificador atual.
